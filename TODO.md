## External data sources / structuring systems

In addition to Dictator's own filesystem/data storage, support linking to external data-structuring systems so Dictator can display and work with data stored elsewhere.

Potential integrations include:

- Dropbox
- OneDrive
- Mindsplosion
- Other external/project/knowledge-management systems

The goal is for Dictator to remain a useful capture and display interface while allowing the underlying structured data to live in the system best suited to it. For example, Mindsplosion could provide project/idea/task context that Dictator can display alongside its own documents.
